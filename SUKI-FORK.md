# About this fork

This is an unmodified reference clone of [`https://github.com/GothenburgBitFactory/taskwarrior.git`](https://github.com/GothenburgBitFactory/taskwarrior.git), pulled in as a
decided component of Suki's stack (the "pull list"). No code changes — this fork exists so the
repo is registered under `justinwalters` on GitHub, checked out on the mini, and registered as
its own independent Orca project, the same pattern used for [`orca`](https://github.com/justinwalters/orca).

Read the reasoning behind why this component was pulled, what alternatives were considered and
rejected, and what's still open, in the Suki repo:
[`docs/decisions/code-manifest-and-decision-log.md`](https://github.com/justinwalters/suki/blob/main/docs/decisions/code-manifest-and-decision-log.md).

`origin` (this fork) is for Suki's own reference use; `upstream` remains `https://github.com/GothenburgBitFactory/taskwarrior.git`
for pulling updates.
